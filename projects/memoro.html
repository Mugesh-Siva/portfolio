Memoro

An AI-powered memory assistant that continuously captures your voice, stores everything you say, and recalls it on demand. Identity is a 256-bit cryptographic key | no accounts, no passwords, no servers that know who you are.

Overview

Memoro is the final year project, completed in March 2026. The concept is inspired by MIT research into personal AI assistants and the principle of sovereign identity from cryptographic systems. Instead of creating an account, your identity is a randomly generated 256-bit key | similar to a crypto wallet's private key. Lose it and your data is inaccessible to everyone, including the server.

Built with React Native 0.81.5 and Expo SDK 54, the app runs on iOS and Android. The AI layer uses Google Gemini 2.0 Flash, which processes voice-transcribed memory context and responds in 1.5-3 seconds. Memories are stored locally and synced to Cloudinary when online.

Key Features

→

Cryptographic identity: 256-bit key generated via expo-crypto (SHA-256). No username, no email, no password. The key IS you. Stored securely in expo-secure-store.

→

Continuous voice capture: expo-speech transcribes everything you say in real time. Transcriptions are stored as timestamped memories in under 100ms.

→

Dual AI mode: Conversational mode uses the last 20 memories as context. Memory mode uses keyword-scored RAG retrieval (TF-IDF style) across all stored memories for deep recall. Intent detection decides which mode to use automatically.

→

Intent detection engine: 5 pattern categories with 88% true positive accuracy. Detects whether you're asking a question, making a note, requesting recall, describing an observation, or expressing a thought.

→

Security layers: PIN + biometric authentication (Face ID / Fingerprint via expo-local-authentication). Progressive lockout: 30s after 3 failures, scaling up to 24h. Brute-force resistant.

→

Offline-first with auto sync: All memories stored locally (AsyncStorage). When connectivity is detected, memories sync to Cloudinary automatically in the background.

→

Up to 1,000 memories: A circular buffer ensures the oldest memory is evicted when the cap is reached, keeping the local store fast and bounded.

Challenges & Solutions

Identity without a server
Used expo-crypto to generate a 256-bit key at first launch, stored with expo-secure-store. The key is the only thing that can decrypt and access cloud-synced memories | no backend authentication layer needed at all.
Knowing when to use RAG vs. conversational context
The intent detection engine classifies each input before it hits Gemini. If classified as a recall or question intent, the RAG retriever scores all memories by keyword relevance and injects the top-ranked ones into the prompt. For conversational intents, only the last 20 memories are used | keeping token cost low and responses fast.
Brute-force protection without a server
Failure counts and lockout timestamps are stored locally. Each failed attempt doubles the lockout period (30s → 2m → 8m → 24h). The lockout persists across app restarts, so clearing app cache doesn't reset it without wiping storage entirely.
