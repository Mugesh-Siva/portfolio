thecollegeevents.com

India's platform for discovering inter-college technical and cultural events. Colleges register, get admin-approved, and promote events with paid listings powered by Cashfree. Launched December 2025 / January 2026.

Overview

thecollegeevents.com is a live web platform that helps students across India discover inter-college events | technical fests, cultural nights, hackathons, workshops, and sports tournaments. It was built from scratch with React, TypeScript, and Vite, backed by Firebase for authentication and Firestore for real-time data. The platform launched in December 2025 / January 2026.

The platform has a complete multi-role architecture: students discover events, colleges register and manage their profile, and an admin panel handles approvals, disputes, and analytics. Colleges can pay to promote events to a wider audience via Cashfree payment gateway integration.

Key Features

→

Live event discovery: Browse and filter events by city, event type (Technical/Cultural/Sports/Workshop), and date. Events appear as cards with college name, date, city, and type badge.

→

Multi-role system: Students browse and register. Colleges create profiles and post events. Admins approve college registrations, manage reported content, and view analytics.

→

Cashfree payment integration: Colleges pay to promote events on the platform's featured sections. Full payment flow with order creation, status verification, and webhook handling.

→

Gemini AI recommendations: Event recommendation engine powered by Google Gemini API, suggesting events based on student interest patterns and location.

→

Media hosting: College banners and event images stored via Cloudinary. Automatic image optimisation on upload.

→

PWA + SEO: Full service worker setup for offline support, Web app Manifest for install prompts. Structured data (JSON-LD) for events, meta tags, and OpenGraph for sharing. Site is discoverable on Google.

→

Maintenance mode: A global maintenance flag in Firestore triggers a full-screen maintenance page, controllable by admin without a deployment.

→

Typography: DM Sans, Syne, and JetBrains Mono via Google Fonts | the same stack used in this portfolio.

Challenges & Solutions

College approval workflow without a traditional backend
Firebase Firestore security rules enforce that only admins can update the "approved" field on college documents. The admin panel reads a filtered query of pending colleges and updates their status with a single Firestore write | no custom server needed.
Payment webhook verification in a serverless setup
Cashfree webhook events are handled by a Firebase Cloud Function that verifies the HMAC signature before updating the promotion status. This keeps payment logic server-side and secure without managing any infrastructure.
Maintenance mode propagation with no downtime
A single boolean document in Firestore is listened to in real time by the React app. When toggled by an admin, every connected client renders the maintenance screen within milliseconds | zero deployments required.
